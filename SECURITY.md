# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's GitHub Security tab to submit a private vulnerability report.

Include the affected revision, a concise reproduction, the likely impact, and any suggested fix. Remove credentials, cookies, Notion page contents, and Browserbase session details from the report.

You should receive an acknowledgment within seven days. No formal bug bounty is currently offered.

## Supported versions

Security fixes are applied to the latest revision on `main`. This project does not yet publish versioned releases.
